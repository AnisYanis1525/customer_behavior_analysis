# customer_behavior_analysis

Data Analytics Project Focused on Customer Behavior Insights Using Python, SQL, and Power BI


📊 Data Analytics Project: End-to-End Behavior Analysis
🔍 Overview

This project showcases a complete end-to-end data analytics workflow, focusing on behavior analysis using Python, SQL, and Power BI.

The project demonstrates how raw data can be transformed into actionable insights through exploratory analysis, database querying, visualization, and reporting.
It reflects a real-world analytics process commonly used by data analysts in business environments.


📁 Dataset
 
    * The dataset was loaded and analyzed using Python (Pandas).

    * It contains structured data suitable for behavioral and business analysis.

    * Data quality issues such as missing values, duplicates, and inconsistent formats were identified and resolved during the cleaning phase.

The dataset is used strictly for learning and portfolio purposes.



🛠 Tools & Technologies

    * Python (Pandas, NumPy) – Data loading, EDA, and cleaning

    * Jupyter Notebook – Interactive analysis environment

    * MySQL – Writing and executing SQL queries

    * Power BI – Data visualization and dashboard development

    * Gamma.app – Creating a presentation (PPT)

    * GitHub – Version control and project hosting



🔄 Project Workflow

- Data Loading

    * Imported the dataset into Python using Pandas.

- Exploratory Data Analysis (EDA)

    * Analyzed data distribution and summary statistics.

    * Identified trends, patterns, and anomalies.

- Data Cleaning

    * Handled missing values.

    * Corrected data types and inconsistencies.

    * Prepared clean data for analysis and visualization.

- SQL Analysis (MySQL)

    * Loaded cleaned data into MySQL.

    * Wrote SQL queries to answer analytical questions.

    * Cross-validated insights found during Python analysis.

- Power BI Dashboard

    * Built interactive dashboards.

    * Visualized key metrics and behavioral patterns.

    * Enabled filtering for deeper exploration.

- Reporting & Presentation

    * Created a concise analytical report.

    * Built a presentation using Gamma to communicate insights clearly.

📊 Dashboard

The Power BI dashboard highlights:

* Key performance indicators (KPIs)
